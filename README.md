# SinDisk

Нативное приложение для macOS (Apple Silicon) для анализа и очистки диска: карта занятого места, рекомендации по очистке, поиск и дубликаты. Всё удаляется в Корзину, и любую очистку можно отменить.

Техническое задание: <https://claude.ai/artifact/Ns7idzFsiBppJ92RzefCDu>

## Возможности (v0.1)

| Раздел | Что умеет |
| --- | --- |
| Обзор | Заполненность тома, разбивка по типам файлов, самые большие файлы, подсказка про полный доступ к диску |
| Карта диска | Кольцевая диаграмма (sunburst), плитки (treemap) и список; навигация кликом и хлебными крошками, подсказка при наведении, раскраска по типу или возрасту, лоток очистки |
| Рекомендации | 12 категорий: кэши, логи, Корзина, Xcode, кэши разработчика, node_modules, установщики, старые загрузки, большие и давно не открывавшиеся файлы, бэкапы iOS, остатки удалённых программ |
| Дубликаты | Точное сравнение (размер → хэш краёв → полный SHA-256), карта групп по лишнему объёму, правила «какую копию оставить», удаление или замена APFS-клонами |
| Поиск | Имя, маски `*.mov`, `/regex/`, фильтры `size:` `ext:` `kind:` `modified:` `opened:` `in:` `-in:` `type:`; подсветка найденного на карте, экспорт CSV, сохранённые запросы |
| История | Журнал очисток за 90 дней, отмена сессии, график освобождённого места |
| Строка меню | Свободное место и быстрые действия |
| Обновления | Проверка новой версии на GitHub Releases при запуске (раз в сутки) и по команде «SinDisk → Проверить обновления…»; загрузка, сверка SHA-256, проверка подписи, замена и перезапуск |

Защита: системные области, корневые папки пользователя, связка ключей, почта, сообщения и медиатека «Фото» не удаляются ни при каких настройках (`SafetyGuard`).

## Как запустить

Нужны macOS 14+ и Xcode 16+ (или Command Line Tools со Swift 5.10+).

```bash
git clone https://github.com/claudesiniakov/sindisk.git
cd sindisk
./scripts/build-app.sh      # соберёт build/SinDisk.app
open build/SinDisk.app
```

Для разработки откройте `Package.swift` в Xcode и запустите схему `SinDisk`, или выполните `swift run SinDisk`.

Готовую сборку можно скачать в разделе Actions (артефакт `SinDisk-app`) или в Releases. Сборка подписана ad-hoc, без Developer ID, поэтому при первом запуске macOS её заблокирует. Откройте её через правый клик → «Открыть» или выполните `xattr -dr com.apple.quarantine SinDisk.app`.

После запуска выдайте SinDisk **полный доступ к диску**: «Системные настройки → Конфиденциальность и безопасность → Доступ к диску». Без него macOS скрывает Корзину, почту и часть кэшей.

## Обновления

Приложение берёт последний релиз из `claudesiniakov/sindisk`. Архив скачивается только по HTTPS с github.com и сверяется с `SinDisk.zip.sha256` из того же релиза. Перед установкой проверяются идентификатор пакета, номер версии и `codesign --verify`. Старая версия заменяется после выхода из приложения, при ошибке она восстанавливается. Если нет прав на запись в папку с приложением, SinDisk открывает страницу релиза.

Выпуск новой версии: `git tag -a vX.Y.Z -m "..." && git push origin vX.Y.Z`. CI соберёт приложение, посчитает контрольную сумму и опубликует релиз с автоматическим списком изменений.

```
Tests/SinDiskCoreTests тесты ядра (swift test)
scripts/build-app.sh  сборка .app и zip
```
